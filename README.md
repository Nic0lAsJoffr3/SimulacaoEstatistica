# Simulação Estatística Interativa

Este projeto foi desenvolvido como atividade acadêmica para a disciplina de Estatística, com o objetivo de transformar conceitos teóricos em uma simulação visual e interativa.

A aplicação demonstra, na prática, como a **média amostral** e o **erro estatístico** se comportam conforme o número de sorteios aumenta, permitindo observar a **convergência estatística** ao longo do tempo.

---

## Objetivo

O principal objetivo do projeto é facilitar o entendimento de conceitos estatísticos como:

- Média amostral
- Desvio padrão
- Variância
- Convergência da média
- Lei dos Grandes Números (visualização prática)

---

## Como funciona

O sistema realiza sorteios aleatórios contínuos de valores dentro de um intervalo definido.  

A cada iteração:

- Um valor é sorteado aleatoriamente
- As frequências são atualizadas
- A média amostral é recalculada
- O erro estatístico é estimado
- Os gráficos são atualizados em tempo real

---

## Visualizações

O projeto apresenta duas visualizações principais:

- **Gráfico de distribuição (barras)**  
  Mostra a frequência de cada valor sorteado.

- **Gráficos de convergência**
  - Evolução da média amostral
  - Evolução do erro estatístico
